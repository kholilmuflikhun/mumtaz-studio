# Mumtaz Studio: product foundation

## Product
Mumtaz Studio is a standalone, hybrid vector illustration, layout, and print-design application for web and desktop.

## Audience
Individuals, designers, educators, students, creators, print shops, and businesses. Start with accessible defaults and advanced tools progressively disclosed.

## Phase 1 priorities
1. Establish downstream product naming in visible app UI and documentation.
2. Add a coherent, accessible design system while retaining keyboard workflows.
3. Verify web and desktop file handling, import, export, and offline behavior.
4. Review Indonesian and English localization.
5. Add release automation with reproducible checks.
6. Track upstream synchronization and feature parity.

## Non-goals for initial foundation
- Rewriting the existing document engine.
- Introducing mandatory sign-in, paywalls, or cloud sync.
- Claiming complete format fidelity before verified round-trip tests.
- Replacing native and browser applications with separate incompatible engines.

## Branding and provenance
Visible product branding may say Mumtaz Studio, but original copyright and required third-party attribution must remain intact. Package names and file extensions should change only with a migration and compatibility plan.
