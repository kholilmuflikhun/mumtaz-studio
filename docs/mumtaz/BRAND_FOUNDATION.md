# Mumtaz Studio brand foundation

Status: initial vector mark concept. This is a downstream product identity, not an upstream TraceDraw asset.

## Identity direction

- Product name: Mumtaz Studio
- Product category: vector illustration, page layout, and print-design application
- Brand attributes: precise, capable, approachable, creator-focused
- Visual direction: modern geometric, restrained, high contrast

## Core palette

| Token | Hex | Use |
|---|---|---|
| Deep navy | `#13243D` | Primary brand field |
| Sky blue | `#7FC3FF` | Accent and active detail |
| White | `#FFFFFF` | Primary mark and text |
| Existing app blue | `#1A3158` | Transitional application UI background |

## Mark

The first original mark is `assets/brand/mumtaz-studio-mark.svg`. It uses a geometric M monogram with a sky-blue center detail on a deep navy rounded square.

## Usage rules

1. Keep the mark's proportions and colors; do not stretch or skew it.
2. Preserve clear space around the mark equal to at least 10% of its canvas width.
3. Use the mark on light or neutral backgrounds only when the navy field remains intact.
4. Use the wordmark "Mumtaz Studio" in product UI; do not substitute the upstream name in user-facing surfaces.
5. Keep upstream copyright, license notices, and attribution in legal/about contexts where required.
6. Do not imply endorsement by TraceDraw upstream contributors.

## Migration boundary

This SVG is an original source asset only. Existing PNG, ICO, ICNS, Android density, and Microsoft Store icon assets remain unchanged until matching raster exports are generated and verified at every required size. The current app continues using those existing icons temporarily; the new mark is not yet wired into release packages.


## Master logo

The approved master logo source is `assets/brand/mumtaz-studio-master.svg`. Use this full lockup as the canonical README and brand reference. It combines the navy emblem, white geometric M, electric-blue ribbon, amber accent, Mumtaz Studio wordmark, and the tagline “Studio Kreatif untuk Desain Teknis & Dokumen Visual”. Keep the SVG as the source of truth for future raster exports. Do not replace platform icons until each required size and transparent/background variant has been exported and visually checked.
